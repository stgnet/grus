Import an archive

Each thread becomes a locked archive thread. Authors' names are scrubbed from the text and never come across. Importing the same file again updates the threads in place.

Measure a model

{{if .HasModel}}

Runs digests, link checks and link notes on a sample of the archive's threads, through the same code the site uses, and reports how many an hour. With questions, it also reports how often an expected thread made the top three and how long 90% of searches took (the site gives up at 8 seconds). Try two or three models, then set the chosen one as ai_model in the global settings.

Load test

Reads the group's public pages (its front page, FAQ, and every post the front page links to) as signed-out visitors, from this node, and reports pages a second and how long they took. It only reads. Try stopping a node partway through: the others should carry on without a pause.
