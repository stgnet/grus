Domains

Every domain here is the whole site: the same groups and content, answered by every node. A request is answered in the domain it came in on, so each domain's DNS can point at different nodes, and a node can be tried out by the domain that leads to it. Set up a domain's DNS first (docs/dns.md), for the bare name and *. the name.
